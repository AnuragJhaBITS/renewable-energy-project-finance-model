# Renewable energy Project Finance Model

A dynamic Excel-based project finance model developed to evaluate the financial feasibility of a 50 MW utility-scale solar power plant.

## Features

- Revenue Forecasting
- Operating Cost Modeling
- Working Capital Schedule
- Depreciation Schedule
- Debt Amortization
- Equity Cash Flow (FCFE)
- Equity IRR & NPV
- Debt Service Coverage Ratio (DSCR)
- Two-Variable Sensitivity Analysis

## Key Metrics

- Equity IRR
- Equity NPV
- Minimum DSCR
- Average DSCR
- Gearing Ratio

## Tools Used

- Microsoft Excel
- Named Ranges
- PMT / PPMT
- IRR / NPV
- Data Tables
- Conditional Formatting

## Skills Demonstrated

- Financial Modeling
- Project Finance
- Renewable Energy Valuation
- Debt Structuring
- Sensitivity Analysis
- Corporate Finance
